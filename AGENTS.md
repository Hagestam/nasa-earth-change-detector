
# Africa Environmental Change Monitor

## Project Objective
Build an environmental change detection platform
for analysing Earth science data across Africa.

## My Development Focus
Scientific analysis and LLM interpretation.

## Scientific Principles
- Statistical calculations must be reproducible.
- Never fabricate measurements or results.
- Separate statistical analysis from LLM interpretation.
- Document statistical assumptions.
- Account for seasonality and autocorrelation.
- Communicate uncertainty.
- Distinguish statistical significance from practical importance.

## Development Rules
- Use Python type hints.
- Write modular, maintainable functions.
- Include unit tests.
- Handle missing data appropriately.
- Never hardcode environmental results.
- Use environment variables for API credentials.
- Follow the agreed API contract.

## File Ownership
Primary ownership:
- backend/app/services/analysis.py
- backend/app/services/interpretation.py
- backend/tests/

Do not modify other developers' files without coordination.

## Workflow
- Work on the assigned Git branch.
- Make incremental commits.
- Run tests before committing.
- Explain significant implementation decisions.
